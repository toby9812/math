🎯 系統理念

傳統 AI 解數學題常有兩大痛點：一是容易「計算幻覺」（心算算錯卻一本正經胡說八道），二是「直接把整份解答全倒給學生」，導致學生喪失思考機會。本系統為此特別設計三大防禦關卡：

步驟 0
題意轉錄確認（tutor_coordinator）

不論輸入文字或圖片，家教都會先拆解已知條件與求解目標向你確認，避免抄錯數字白忙一場。

步驟 1
Python 雙軌程式驗證（math_solver）

確認題目後，系統會透過後端沙盒自動執行 Python（SymPy 符號運算 vs 代數/枚舉檢驗）雙軌雙驗證，兩軌答案一致才會採用！你可以在對話中點開「🐍 Python 驗證紀錄」檢視實際運算的程式碼。

步驟 2
SHAPE 碎步鷹架導引（shape_tutor）

一次只推一步（3 句話內 + 1 個引導問句）。學生答對會得到生活化概念鼓勵；答錯則精準指出第幾步卡關，陪你一步一步自己解出來！

💡 卡關時的「提問導航」

如果引導過程中思考遇到瓶頸，你可以隨時這樣問家教：

  • 【What 觀念】「這個公式背後的幾何意義是什麼？」
  • 【How 步驟】「上一步到這一步是怎麼推導出來的？」
  • 【Why 方法】「為什麼這題用這個定理會比另一個快？」
